#  1. Copiez ce fichier vers "account.txt" :
#         cp account.example.txt account.txt      (Linux / macOS)
#         copy account.example.txt account.txt    (Windows)

#  2. Remplacez TOUTES les valeurs "REMPLACEZ_MOI" par vos vraies valeurs.

#  IMPORTANT : ce fichier donne un accès complet à votre compte Facebook.

# ----------------------------------------------------------------------------
#  FORMAT A (RECOMMANDE) — appState : tableau JSON de cookies
# ----------------------------------------------------------------------------

#  "Cookie-Editor" / "EditThisCookie" (fonction "Export as JSON"), ou avec
#  l'outil "c3c-fbstate". Collez le résultat ci-dessous.
#
#  Les cookies indispensables sont : c_user, xs, datr, fr, sb.
#  Les lignes commençant par "#" sont ignorées.
#
# ----------------------------------------------------------------------------
#  FORMAT B — chaîne de cookies brute (une seule ligne)
# ----------------------------------------------------------------------------
#  Effacez le bloc JSON ci-dessous et mettez simplement :
#
#      c_user=100000000000000; xs=ABCdef123; datr=XYZ; fr=0abc...; sb=0abc...;
#
# ----------------------------------------------------------------------------
#  FORMAT C — identifiants (DECONSEILLE : déclenche souvent des checkpoints)
# ----------------------------------------------------------------------------
#      email=votre@email.com
#      password=votre_mot_de_passe
#
#  Pour ce format, préférez les variables d'environnement FB_EMAIL /
#  FB_PASSWORD (voir .env.example) plutôt qu'un fichier.
#
# ----------------------------------------------------------------------------
#  SUR RENDER (le disque est éphémère) :
#  utilisez la variable d'environnement FB_APPSTATE avec le contenu JSON,
